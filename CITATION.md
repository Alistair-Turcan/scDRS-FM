# Citation

If you use this repository, cite this code repository and the upstream methods and software that your analysis depends on.

For the original scDRS method, cite:

Zhang, M. J., Hou, K., Dey, K. K., Sakaue, S., Jagadeesh, K. A., Weinand, K., et al. Polygenic enrichment distinguishes disease associations of individual cells in single-cell RNA-seq data. *Nature Genetics* (2022).

Also cite AnnData, Scanpy, and any imputation method used in your analysis where appropriate.
