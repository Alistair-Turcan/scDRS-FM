# Usage

## End-to-end scDRS-FM scoring

```bash
scdrs-fm \
  <input.h5ad> \
  <covariates.tsv|none> \
  <output_dir> \
  <gene_set_dir> \
  <trait_1.gs> [<trait_2.gs> ...] \
  --h5ad_species human \
  --flag_raw_count \
  --flag_filter \
  --imputation magic
```

### Minimal example

```bash
scdrs-fm data/expr.h5ad none results data/gene_sets coronary_artery_disease.gs --imputation none
```

### Multiple traits

```bash
scdrs-fm data/expr.h5ad data/cov.tsv results data/gene_sets trait_a.gs trait_b.gs trait_c.gs
```

### Include control scores

Control scores are useful for downstream empirical tests but can make output files much larger.

```bash
scdrs-fm data/expr.h5ad data/cov.tsv results data/gene_sets trait_a.gs --include_ctrl_score
```

## Phenotype-gradient decomposition

Run this after you have scDRS-FM trait outputs and phenotype score tables.

```bash
scdrs-fm-decompose \
  --traits trait_a.gs trait_b.gs \
  --trait_dir results/scdrs_fm \
  --pheno_dir results/phenotypes \
  --out_dir results/decomposition \
  --adata data/expr.h5ad \
  --phenotypes phenotype_1 phenotype_2 phenotype_3 \
  --n_controls 1000
```

Optional filters:

```bash
scdrs-fm-decompose \
  --traits trait_a.gs \
  --trait_dir results/scdrs_fm \
  --pheno_dir results/phenotypes \
  --out_dir results/decomposition_tcells \
  --adata data/expr.h5ad \
  --phenotypes phenotype_1 phenotype_2 \
  --cell_type_col cell_type \
  --cell_type T_cell
```

## Recommended workflow

1. Prepare the `.h5ad` object with meaningful `obs_names` and gene symbols in `var_names`.
2. Prepare a covariate TSV or decide to disable covariate correction.
3. Prepare scDRS-style gene-set files.
4. Run `scdrs-fm` for a small trait/data subset with `--imputation none` to validate formats.
5. Run the full scoring command with your chosen preprocessing/imputation options.
6. Inspect marginal and conditional score distributions.
7. Optionally run phenotype-gradient decomposition.

## Performance considerations

- Marginal scoring densifies `adata.X`; use a machine with RAM appropriate for `n_cells × n_genes`.
- Control-score output (`--include_ctrl_score`) can be very large because 1,000 control columns are generated by default.
- Run one or a few traits first to estimate memory and wall-clock time.
